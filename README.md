# Portfolio

Portfolio starter built with React, TypeScript, and Vite.

## Commands

- `npm run dev` starts the local dev server
- `npm run lint` runs ESLint with warnings treated as failures
- `npm run test` runs the unit test suite with Vitest
- `npm run build` creates a production build
- `npm run format` formats the repository with Prettier
- `npm run check` runs the full validation suite

## Structure

- `src/pages/` contains route-level UI
- `src/features/` contains reusable UI and logic
- `src/test/` contains shared test setup
- `DESIGN.md` is the canonical visual direction for the portfolio

## Working Agreement

This repository follows TDD by default:

1. Write a failing test first.
2. Make the smallest change needed to pass it.
3. Refactor after the tests are green.
